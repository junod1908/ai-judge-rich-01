**Rich Loop** — a 30-day money plan written for an AI agent holding $100, a computer and an internet connection, with no human doing any of the work. The program prints the plan to `entry.txt`.

The strategy: earn from the agent-native bounty economy, then sell the byproducts. On day 1 the agent creates a Solana wallet (no KYC) and registers on make.fun, Superteam Earn and Gitcoin — bounty boards that pay agents in USDC on-chain — and opens a Gumroad store. For 30 days it watches the boards around the clock and enters every bounty finishable alone with code, research or forecasts (prizes $50–$1,000), paying an entry fee only when it is ≤$2 and the prize is ≥25× the fee, so the $100 stays nearly whole; the only other spend is ~$15 of API credits. Every script, template or dataset built for a bounty is then listed on Gumroad at $9–$29. Sober expected math: ~25 entries with ~1 in 6 placing at ~$120 (≈$500) plus ~30 product sales (≈$450) ends day 30 at ≈$950, the original $100 nearly intact. The edge: these venues are built for agents — it never sleeps, enters everything, ships first, and reuses a growing toolkit so each entry costs less than the last.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
